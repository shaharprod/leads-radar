1. התחלה: מה צריך לפני הסריקה הראשונה

הכלי רץ בדפדפן, בלי התקנה. כדי שהוא יוכל לשאול את גוגל על עסקים, הוא צריך מפתח API שלך. בלי מפתח, כפתור הסריקה לא יעבוד.

  1. מפתח Google Maps Platform (חובה). ההנחיות המלאות בפרק 2. לוקח כ-10 דקות בפעם הראשונה.
  2. המיתוג שלך (מומלץ לפני הדוח הראשון). פרק 3.
  3. מפתח Gemini (אופציונלי, לניסוח פניות ב-AI ולערכת תוכן). פרק 15.
  4. שרת ביקורת העומק — מוגדר מראש, אין מה להקים. פרק 7.
טיפ: הכלי זוכר את ההגדרות והסריקות בדפדפן שבו עבדת. אם תפתח אותו בדפדפן אחר או במחשב אחר, תצטרך להזין את ההגדרות שוב. בפרק 17 מוסבר למה זה כך ואיך לגבות.

2. מפתח Google, צעד אחר צעד

כל הקישורים כאן מופיעים גם בתוך הכלי, בחלון ⚙️ הגדרות, מתחת לשדה המפתח.

  1. היכנסו ל-Google Cloud Console עם חשבון Google הרגיל שלכם. אם זו הפעם הראשונה, אשרו את תנאי השימוש.
  2. צרו פרויקט. בסרגל העליון, לחצו על רשימת הפרויקטים ← New Project. שם לדוגמה: "leads-radar". לחצו Create והמתינו כמה שניות עד שהפרויקט נבחר.
  3. הפעילו חשבון חיוב. גוגל דורשת כרטיס אשראי כדי להפעיל את Maps, גם לשימוש בתוך המכסה החינמית. מסך החיוב ← Link a billing account או Create account. אתם לא מחויבים כל עוד אתם בתוך המכסה החודשית.
  4. הפעילו 5 שירותים (API). בכל אחד מהקישורים לחצו Enable (אם כתוב Manage, השירות כבר מופעל):
    • Maps JavaScript API: המפה עצמה.
    • Places API (New): פרטי העסקים, הדירוגים והביקורות.
    • Geocoding API: הפיכת כתובת לנקודה על המפה.
    • PageSpeed Insights API: מדידת מהירות האתרים (אופציונלי בסריקה).
    • Chrome UX Report API: המדד "תנועה אמיתית לאתר" בציון החיוניות (חינמי).
    אופציונלי, באותו מפתח (כולם בתוך המכסה החינמית בשימוש רגיל; בלי הפעלה הכלי פשוט מדלג): Generative Language API (AI, פרק 15) · Street View Static API (חזית העסק בדוח) · Maps Static API (מפת מתחרים בדוח) · Safe Browsing API (אתר מסוכן/פרוץ) · Knowledge Graph Search API (ישות מותג). מה כל אחד נותן: פרק 21. אם הגבלתם את המפתח לשירותים מסוימים — הוסיפו גם אותם לרשימה.
  5. צרו מפתח. מסך Credentials ← + Create credentials ← API key. העתיקו את המפתח (מתחיל ב-AIza).
  6. הגבילו את המפתח (מומלץ מאוד). באותו מסך לחצו על שם המפתח ← תחת Application restrictions בחרו Websites והוסיפו את כתובת הכלי (למשל https://shaharprod.github.io/*). תחת API restrictions בחרו Restrict key וסמנו רק את 5 השירותים מהסעיף הקודם. לחצו Save. כך גם אם המפתח ידלוף, אי אפשר להשתמש בו ממקום אחר.
  7. הדביקו בכלי. ⚙️ הגדרות ← שדה Google Maps API Key ← שמור. המפה אמורה להיטען מיד.
שליטה בהוצאות: במסך המכסות של Maps אפשר לקבוע תקרה יומית לכל שירות. הגדרה שמרנית לדוגמה: 2,000 בקשות ליום ל-Places. סריקה עמוקה (19 נקודות) יכולה לצרוך כמה עשרות בקשות, וביקורת עומק עוד כמה לכל עסק. במסך החיוב אפשר גם להגדיר התראת תקציב.

3. המיתוג שלך: שם, לוגו, כתובת, פרטי קשר

איפה: בכלי, בסרגל העליון ← ⚙️ הגדרות ← החלק "🏷️ המיתוג שלך בדוחות (White-Label)" ← בסוף שמור. המדריך הזה נפתח מכפתור ❓ עזרה באותו סרגל.

כל מה שתמלאו כאן יופיע על הדוחות, הצעות המחיר, ערכות התוכן והפניות שהכלי מפיק. הלקוח שלכם רואה אתכם, לא אותנו.

4. סריקה ראשונה

איפה: לשונית 🔍 סריקה.

  1. אזור הסריקה. הקלידו כתובת, עיר או אזור ולחצו 📍 מצא על המפה, או גררו את הסיכה הכחולה למקום הרצוי. אפשר גם ללחוץ על המפה.
  2. רדיוס. המחוון קובע כמה רחוק מהמרכז לסרוק (1–10 ק"מ). התחילו ב-3 ק"מ בעיר, 5–10 באזור כפרי.
  3. מה מחפשים. מילת חיפוש חופשית (מומלץ, למשל "קליניקת שיניים" או "מוסך") או קטגוריה מהרשימה.
  4. עומק סריקה. מהיר: נקודה אחת, מהיר וזול, מתאים לבדיקה. בינוני: 7 נקודות. עמוק: 19 נקודות סביב המרכז, מוצא גם עסקים שגוגל מסתירה בחיפוש רגיל, אבל צורך יותר קריאות API.
  5. סינון תוצאות (אופציונלי לפני הסריקה): "בלי אתר אינטרנט", "פחות מ-20 ביקורות" וכו'. אפשר גם לסנן אחרי.
  6. לחצו 🔍 התחל סריקה. התוצאות מופיעות על המפה ובכרטיסים מתחת, תוך כדי הסריקה. אפשר לעצור בכל רגע.
סריקה חוזרת של אותו אזור מוסיפה עסקים חדשים לרשימה ולא מוחקת. כדי להתחיל נקי: 🗑️ נקה תוצאות. הלידים שסימנתם במשפך (פרק 12) לא נמחקים.

5. מה אומרים הצבעים והמספרים

ציון ההזדמנות (הריבוע בפינת הכרטיס)

הציון הוא 100 פחות הנוכחות הדיגיטלית של העסק. נוכחות נמדדת משלושה חלקים: כרטיס גוגל (עד 45 נקודות), אתר (עד 35), שיווק ומדידה (עד 20). ככל שחסר לעסק יותר, הציון גבוה יותר, ויש לכם יותר מה למכור לו.

לפני ביקורת עומק (פרק 7) הציון חלקי ומבוסס רק על נתוני גוגל. אחרי הביקורת הוא מדויק.

💓 חיוניות

כמה העסק חי: קצב הביקורות, מתי הייתה הביקורת האחרונה, שעות פתיחה, תנועה לאתר, עדכונים ורשומות רשמיות. 🟢 70+ פעיל ומתרחב · 🟡 45–69 יציב · 🔴 מתחת ל-45 רדום. עסק עם ציון הזדמנות גבוה אבל חיוניות נמוכה הוא כנראה עסק גוסס, לא ליד.

🏆 "ההזדמנויות הטובות ביותר"

המיון המומלץ. לוקח את ציון ההזדמנות ומוסיף נקודות אם יש דרך להשיג את העסק (טלפון, וואטסאפ, מייל) ואם הוא פעיל, ומוריד עסקים סגורים ולידים שסימנתם "לא רלוונטי". המספר #1, #2 בכרטיס הוא המקום במיון הזה.

6. סינון ומיון: איך למצוא את הלידים הכי שווים

אחרי הסריקה, השתמשו בסינון ובמיון שמעל רשימת הכרטיסים:

  • 💎 עסק חי + נוכחות חלשה: הסינון הכי שווה. עסק שעובד, מקבל ביקורות, אבל אין לו אתר או מדידה. אלה הלקוחות שישלמו.
  • בלי אתר אינטרנט: למי שמוכר בניית אתרים.
  • בלי פיקסל / Analytics, בלי הצהרת נגישות: זמינים אחרי ביקורת עומק. למי שמוכר שיווק דיגיטלי או נגישות.
  • בלי מדיניות פרטיות, בלי תנאי שימוש / תקנון, 🛡️ חשיפה משפטית גבוהה: זמינים אחרי ביקורת עומק. למי שמוכר התאמה לחוק: הצהרת נגישות, מדיניות פרטיות ותקנון. ראו פרק 7, "חשיפה משפטית".
  • פחות מ-20 ביקורות: למי שמוכר ניהול מוניטין וביקורות.
  • 🔴 עסקים רדומים: בדרך כלל לא לידים. שימושי כדי להוציא אותם מהרשימה.

מיון לפי מרחק עוזר לתכנן סבב ביקורים פיזי; מיון לפי מספר ביקורות מוצא את העסקים הגדולים באזור. 🛡️ מיון: חשיפה משפטית מסדר את העסקים מהחשיפה הגבוהה לנמוכה (אחרי ביקורת עומק) — עסקים שלא נותחו או שאתרם חסם את הבדיקה מופיעים בסוף. למי שמוכר התאמה לחוק: סינון "🛡️ חשיפה משפטית גבוהה" + המיון הזה = רשימת הפנייה.

7. ביקורת עומק

איפה: 🔬 נתח את כל העסקים בפאנל הסריקה, או 🔬 חפירה מלאה בכרטיס בודד.

הביקורת בודקת לכל עסק: אתר (מובייל, SEO, SSL, מהירות), פיקסלים ו-Analytics, צ'אט ומערכת תורים, רשתות חברתיות, מיילים, וואטסאפ, נגישות, מדיניות פרטיות ותקנון (ראו חשיפה משפטית בהמשך הפרק), ו-5 הביקורות האחרונות בגוגל. אחריה ציון ההזדמנות מתעדכן והתגיות בכרטיס מתמלאות.

  • מדידת מהירות PageSpeed: מוסיפה כ-20 שניות לעסק. שווה כשמוכרים אתרים.
  • ניתוח ביקורות גוגל: קריאת API נוספת לעסק. נותן את הטענות החוזרות של הלקוחות.
  • אפשר ⏹ עצור בכל רגע. אתר שלא עונה מסומן כשגיאה ולא תוקע את התהליך.
שרת ביקורת העומק: הוא זה שמבצע את «🔬 נתח» / «חפירה מלאה», את בדיקת הנגישות · פרטיות · תקנון, רשם החברות והרישיונות. הכתובת מוגדרת מראש בכלי ואין צורך לעשות כלום. אם «נתח» מחזיר "לא הוגדר שרת ביקורת": ⚙️ הגדרות ← «שרת ביקורת העומק» ← 🔌 בדוק חיבור; אם השדה ריק — ↺ שחזר ברירת מחדל ← שמור.
  • מה לא כלול בשרת המובנה: קישור חי לדוח עם מעקב צפיות, מעקב שבועי על אזורים וחפירה ברשת. אלה עובדים רק עם שרת פרטי משלכם (הסעיף הבא). ערכת תוכן וניסוח ב-AI עובדים עם מפתח Gemini שלכם — בלי שרת.
  • שרת פרטי משלכם (מתקדם, אופציונלי, בחשבון Google שלכם): פונקציה ב-Google Cloud ← Cloud Run בשם leads-radar-audit. הכתובת בשורת URL בדף השירות; הטוקן הוא משתנה הסביבה LR_TOKEN (Cloud Run ← השירות ← Containers ← Variables & Secrets). מדביקים את שניהם בהגדרות.

🛡️ חשיפה משפטית: נגישות, פרטיות ותקנון

בכל ביקורת עומק השרת מחפש באתר העסק שלושה מסמכים שכל אתר עסקי בישראל צריך להציג, פותח כל אחד מהם ובודק שהוא באמת המסמך הנכון (ולא עמוד ריק או עמוד שגיאה):

מסמךמה נבדקהבסיס בחוק
הצהרת נגישותקישור בדף הבית (או בכתובות נפוצות כמו /accessibility), תוכן ההצהרה: פרטי רכז/ת נגישות, ציון התקן (ת"י 5568 / WCAG), תאריך עדכון. בנפרד: האם מותקן רכיב נגישות (Nagich, EqualWeb, UserWay, Enable, accessiBe, Vee, נגיש בקליק ועוד)תקנות שוויון זכויות לאנשים עם מוגבלות (התאמות נגישות לשירות) — פיצוי עד 50,000 ₪ ללא הוכחת נזק. הסבר בכל-זכות
מדיניות פרטיותקישור ועמוד אמיתי; האם האתר אוסף פרטים אישיים (טופס, קביעת תור, דיוור) — אז החשיפה גבוהה יותר; האם יש כלי מעקב (פיקסל, Analytics) בלי הודעת עוגיותחוק הגנת הפרטיות, סעיף 11, ותיקון 13 (בתוקף מ-14.8.2025) שהרחיב את סמכויות האכיפה של הרשות להגנת הפרטיות
תנאי שימוש / תקנוןקישור ועמוד אמיתי; האם האתר מוכר או מתאם תורים אונליין — אז חובה; האם התקנון כולל מדיניות ביטולחוק הגנת הצרכן, סעיף 14ג (עסקה מרחוק)

ציון החשיפה (0–100) מסכם את הממצאים: 🔴 60 ומעלה חשיפה גבוהה · 🟡 30–59 בינונית · 🟢 מתחת ל-30 נמוכה. הציון מופיע כתגית בכרטיס, בפירוט בכרטיס המלא (עם קישור לכל מסמך שנמצא), כפרק נפרד בדוח הממותג, בעמודות הייצוא ל-CSV, ובהצעת המחיר (החבילה המתאימה נבחרת לפי המסמך החסר בלבד).

שני מצבים שבהם הכלי אומר "לבדוק ידנית" ולא נותן ציון: אתר שחסם את הסריקה האוטומטית (קוד 403 וכדומה), ואתר שנבנה בטכנולוגיה דינמית שבה הקוד מגיע כמעט ריק. במקרים אלה פתחו את האתר בדפדפן לפני שפונים לבעל העסק.
ניסוח מול הלקוח: הבדיקה מצביעה על מה לא נמצא באתר. היא אינה ייעוץ משפטי ואינה קביעה שהעסק מפר חוק, וכך גם מנוסח הדוח. אמרו "לא מצאנו באתר הצהרת נגישות" ולא "אתה עובר על החוק".

8. כרטיס העסק המלא

לחיצה על כרטיס פותחת אותו. בפנים: כל הפרטים, הביקורות, רשימת הליקויים עם "פוטנציאל שיפור" לכל אחד, השוואה ל-3 המתחרים החזקים באותה קטגוריה עד 3 ק"מ, ובדוק דירוג מקומי: מפת חום של המקום של העסק בתוצאות גוגל מפות מ-9 או 25 נקודות סביבו. זה הנתון שמשכנע בעלי עסקים: "אתה במקום 7 ברחוב שלך".

בתחתית הכרטיס: שלב במשפך, הערות, איש קשר ותאריך מעקב (פרק 12).

9. דוח ממותג וקישור חי

איפה: 📄 דוח בכרטיס.

הדוח נפתח בלשונית חדשה: דוח "נוכחות דיגיטלית" בעברית, עם הלוגו, הצבע ופרטי הקשר שלכם, ציון, רשימת הממצאים, ובסוף כפתור לתיאום שיחה. שתי דרכים לשלוח אותו:

  • PDF: בלשונית הדוח, Ctrl+P ← "שמור כ-PDF". מתאים לשליחה במייל.
  • קישור חי (דורש שרת ביקורת): 🔗 קישור חי מעלה את הדוח ומחזיר כתובת. הכלי מראה 👁️ כמה פעמים ומתי הלקוח פתח אותו. פתיחה שנייה ושלישית = לקוח מתעניין.
בדוח אפשר ללחוץ על טקסטים ולערוך אותם לפני השמירה כ-PDF. כך מתאימים את הניסוח ללקוח ספציפי.

10. הצעת מחיר והערכת הפסד

איפה: 💰 הצעת מחיר בכרטיס. המחירון: ⚙️ הגדרות ← "💰 הצעות מחיר והערכת הפסד".

ההצעה נבנית אוטומטית: לכל ליקוי שנמצא, הכלי בוחר את החבילה המתאימה מהמחירון שלכם. עדכנו את המחירון לפני ההצעה הראשונה: שורה לכל חבילה בפורמט קטגוריה|שם השירות|מחיר. הקטגוריות: web (אתר), seo, legal (נגישות), rev (ביקורות), gbp (פרופיל גוגל), mkt (מדידה ופרסום), soc (רשתות), conv (המרות: וואטסאפ, טפסים, בוט).

הערכת הפסד חודשי היא המספר שמניע לפעולה: "שווי לקוח ממוצע" × "פניות חודשיות משוערות מגוגל" שהעסק מפספס. שני המספרים בהגדרות. השתמשו במספרים שאתם יכולים להגן עליהם בשיחה.

בהצעה אפשר ללחוץ על כל טקסט או מחיר ולערוך לפני השמירה כ-PDF. הסכומים לא מתעדכנים אוטומטית אחרי עריכה ידנית.

11. פנייה ללקוח: וואטסאפ, מייל, תסריט שיחה

איפה: 📲 וואטסאפ או ✉️ פנייה בכרטיס; 📲 תור וואטסאפ מעל הרשימה.

הכלי מנסח פנייה לפי הליקויים הספציפיים של העסק: הודעת וואטסאפ, מייל, תסריט לשיחת טלפון והודעה לרשתות. בלי מפתח Gemini הפניות נבנות מתבניות; עם מפתח, ב-AI (פרק 15). לפני השליחה, קראו וערכו: פנייה אישית שמזכירה פרט אמיתי ("ראיתי שיש לכם 38 ביקורות מצוינות ואין אתר") עובדת פי כמה מתבנית.

תור וואטסאפ עובר ליד אחרי ליד: לכל אחד נפתח וואטסאפ עם ההודעה המוכנה, אתם קוראים, מתקנים ושולחים, ועוברים לבא. מתאים ל-20–30 פניות ביום.

🔁 סדרת מעקב בחלון הפנייה: 3 הודעות (היום / 3 ימים / שבוע) עם תזכורות ב📋 הלידים שלי.

חשוב לפני ששולחים: קראו את פרק 16 על שימוש חוקי. פנייה אישית לעסק היא בסדר; דיוור המוני ללא הסכמה הוא עבירה על חוק הספאם.

12. משפך הלידים ומעקב

איפה: לשונית 📋 הלידים שלי.

בכל כרטיס בוחרים שלב: חדש ← פניתי ← בשיחה ← הצעה נשלחה ← לקוח (או "לא רלוונטי"). כל עסק שקיבל שלב נשמר במשפך לתמיד, גם אחרי סריקות חדשות ואחרי "נקה תוצאות". לכל ליד: הערות, שם איש קשר, תאריך מעקב. לחיצה על כרטיס במשפך פותחת אותו.

הרגל טוב: כל יום, 10 דקות במשפך. מי שתאריך המעקב שלו היום, פונים שוב.

13. מעקב שבועי על אזורים

איפה: ⭐ מעקב שבועי על האזור הזה בפאנל הסריקה; התוצאות ב📋 הלידים שלי ← "🛰️ מעקב אזורים". דורש שרת ביקורת.

שומרים אזור ותחום. בכל יום ראשון בבוקר השרת סורק אותם מחדש ומזהה עסקים שלא היו שם בשבוע שעבר. עסק חדש הוא הליד הכי חם: הוא עדיין לא בחר ספק, ואין לו כלום. ▶️ בדוק עכשיו מריץ את הבדיקה מיד.

14. ייצוא, Webhook ו-CRM

  • ⬇️ CSV לאקסל: כל התוצאות, עם כל השדות, לפתיחה באקסל או Google Sheets.
  • ⬇️ JSON: לגיבוי או לעיבוד.
  • 🔗 שלח חמים ל-Webhook: שולח את הלידים החמים (70+) לכתובת שהגדרתם ב⚙️ הגדרות ← "Webhook". ב-Make, Zapier או n8n יוצרים Webhook, מדביקים את הכתובת, ומשם מעבירים ל-CRM, לגיליון או למייל. קישורי הדרכה נמצאים בהגדרות מתחת לשדה.

15. ניסוח ב-AI וערכת תוכן (Gemini)

איפה: ⚙️ הגדרות ← "✨ ניסוח פניות ב-AI".

שתי דרכים למפתח Gemini:

  1. מפתח נפרד וחינמי (הכי פשוט): Google AI Studio ← Create API key ← מדביקים בשדה "Gemini API Key".
  2. אותו מפתח Google של המפות: אפשרי, בשני תנאים: (א) בפרויקט שלכם מופעל Generative Language API; (ב) ב-Credentials ← המפתח ← API restrictions — השירות Generative Language API מסומן ברשימת המותרים (אם הגבלתם את המפתח ל-5 שירותי המפות, הוסיפו אותו כשישי).
שגיאות נפוצות ומה הן אומרות: "Gemini API has not been used in project … or it is disabled" = תנאי (א) חסר. "method GenerateContent are blocked" = תנאי (ב) חסר. "This model … is no longer available to new users" = המודל שבהגדרות סגור למפתח שלכם; הכלי עובר לבד למודל Flash אחר ושומר אותו בהגדרות — מספיק לנסות שוב.

עם מפתח Gemini: הפניות מנוסחות מחדש ב-AI בטון אישי לפי הממצאים, ו🎁 ערכת תוכן כותבת לעסק תיאור לגוגל, 3 פוסטים ותשובות לביקורות. מורידים כמתנה ללקוח (זה פותח דלתות) או מצרפים לדוח. המודל בברירת מחדל: gemini-3.8-flash (מהיר וזול); אם הוא לא זמין למפתח שלכם הכלי מנסה לבד gemini-flash-latest ואחרים. ל-Gemini יש מכסה חינמית נדיבה. שימו לב: ניסוח ב-AI וערכת התוכן עובדים עם מפתח Gemini שלכם בלבד — לא דרך שרת הביקורת.

16. שימוש חוקי: מה מותר ומה אסור

הנתונים: הכלי מציג פרטים ציבוריים של עסקים מגוגל מפות ומהאתרים שלהם. אתם, המשתמשים, אחראים לשימוש בהם. הכללים העיקריים בישראל:

  • חוק הספאם (סעיף 30א לחוק התקשורת): אסור לשלוח דבר פרסומת בהודעה אלקטרונית (מייל, SMS, וואטסאפ) ללא הסכמה מראש. פנייה עסקית אישית וחד-פעמית לעסק, שאינה "דבר פרסומת" המוני, היא בדרך כלל מותרת, אבל זה תחום אפור. ההמלצה: פנייה אישית, מותאמת, שמציעה ערך (למשל דוח חינם), ולא תבנית זהה למאות עסקים. שיחת טלפון ופנייה פיזית אינן תחת חוק הספאם.
  • חוק הגנת הפרטיות: הכלי שומר את הנתונים אצלכם, בדפדפן. אם תעבירו אותם ל-CRM, אתם בעלי מאגר ואחראים לאבטחתו. אל תאספו מידע על אנשים פרטיים; הכלי מיועד לעסקים.
  • תנאי Google Maps Platform: אין לשמור נתוני Places לטווח ארוך (מעבר ל-30 יום, למעט מזהה המקום), ואין למכור אותם הלאה כמאגר. הכלי שומר אותם לצורך העבודה השוטפת שלכם, וזו אחריותכם לרענן.
  • בדוחות ובהצעות: אל תבטיחו תוצאות מספריות ("תעלה למקום 1 בגוגל"). הכלי מנוסח כך שלא יבטיח. שמרו על זה גם בעריכה.

האמור כאן הוא הסבר כללי ואינו ייעוץ משפטי.

17. איפה הנתונים שלך נשמרים

הכול בדפדפן שלכם (localStorage): המפתחות, ההגדרות, הסריקות, הלידים וההערות. שום דבר לא עובר לשרת שלנו. המשמעות:

  • יתרון: פרטיות מלאה, ואין מגבלות. גם אם המנוי יסתיים, הנתונים נשארים אצלכם.
  • חיסרון: דפדפן אחר או מחשב אחר לא יראה אותם. ניקוי היסטוריה/עוגיות בדפדפן ימחק אותם.
  • גיבוי: פעם בשבוע ⬇️ JSON לתוצאות, ו⬇️ ייצוא הלידים ל-CSV במשפך. את ההגדרות אפשר לרשום במסמך פרטי.

19. שאלות נפוצות

כמה עסקים אפשר לסרוק?

אין מגבלה מצדנו. המגבלה היחידה היא המכסה של גוגל במפתח שלכם.

אפשר לעבוד מכמה מחשבים?

כן, אבל הנתונים לא מסונכרנים ביניהם (פרק 17). הגדירו את המפתחות והמיתוג בכל אחד.
