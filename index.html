❓ איך זה עובד
1. מפתח API
לוחצים «🔑 מפתח API» למעלה, מדביקים מפתח Google Maps ושומרים. המפתח נשאר בדפדפן שלך בלבד.
2. אזור
כותבים כתובת → «מצא על המפה» → גוררים את הסיכה לדיוק → בוחרים רדיוס (0.5 עד 30 ק״מ).
3. מה מחפשים
מילת חיפוש חופשית בעברית (מדויק יותר) או קטגוריה מהרשימה. «עומק סריקה» קובע לכמה תת-עיגולים מחלקים את האזור — עמוק יותר = יותר עסקים, יותר קריאות API.
4. ציון הזדמנות
0–100. גבוה = ליד טוב יותר — לעסק חסרים דברים שאתה יכול לתקן (אין אתר, מעט ביקורות, אין שעות פתיחה, אין תמונות, דירוג נמוך). בכרטיס המורחב יש פירוט מלא + רשימת שיפורים מוצעים.
5. ניתוח אתר
«🔬 נתח אתר» קורא את דף הבית של העסק ומחלץ: תאימות מובייל, כותרת ותיאור SEO, H1, קישורי פייסבוק / אינסטגרם / וואטסאפ / טיקטוק / יוטיוב / לינקדאין, כתובות מייל, טופס יצירת קשר, Google Analytics, Meta Pixel, מערכת האתר (WordPress/Wix/Shopify) ו-HTTPS.
6. לידים וייצוא
בכל כרטיס מסמנים: חדש / חם / טופל / לא רלוונטי — והסימון נשמר בדפדפן. «ייצוא CSV» פותח באקסל בעברית תקינה.
